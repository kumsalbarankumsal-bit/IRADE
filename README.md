# IRADE

Claude ile yapılmış küçük web uygulamaları.

- `irade.jsx` — İRADE: öz-disiplin ve alışkanlık takip uygulaması (Claude artifact, React).
- `formup/` — **FormUp v2**: temel matematik ve IB Math AA SL formüllerini aralıklı tekrarla, oyunlaştırılmış ve iki dilli (Türkçe + İngilizce) öğrenme uygulaması (WordUp’ın matematik versiyonu). Ayrıntılar `formup/README.md`’de; doğrudan açmak için `formup/dist/index.html`.
