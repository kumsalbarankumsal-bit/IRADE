# IRADE

Claude ile yapılmış küçük web uygulamaları.

- `irade.jsx` — İRADE: öz-disiplin ve alışkanlık takip uygulaması (Claude artifact, React).
- `formup/` — **FormUp**: matematik formüllerini aralıklı tekrarla kalıcı ezberleme uygulaması (WordUp’ın matematik versiyonu). Ayrıntılar `formup/README.md`’de; doğrudan açmak için `formup/dist/index.html`.
